# Netlify Deployment

## Automático desde GitHub:

1. Ve a https://netlify.com
2. "Add new site" > "Import an existing project"
3. Conecta GitHub y selecciona: `naattiiiiiiiii/ElizaVSllm`
4. Branch: `gh-pages`
5. Build command: (dejar vacío)
6. Publish directory: (dejar vacío o `/`)
7. Deploy!

Tu app estará en: `https://NOMBRE-RANDOM.netlify.app`

Puedes cambiar el subdominio en Site Settings > Domain Management.

## Ventajas de Netlify:
- ✅ HTTPS automático
- ✅ Deploy automático en cada push
- ✅ Subdominio personalizable gratis
- ✅ Más rápido que GitHub Pages
- ✅ Analytics incluidos

## Para dominio personalizado:
1. Compra dominio
2. En Netlify: Site Settings > Domain Management > Add custom domain
3. Configura DNS del proveedor según instrucciones de Netlify
